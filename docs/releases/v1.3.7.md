## Axon v1.3.7

Axon v1.3.7 is a terminal reliability and workbench stability release. It
replaces Axon's manual terminal rendering pipeline with xterm's ordered write
and renderer scheduling, corrects the scroll-region behavior that could discard
terminal history, and ensures development uses the same patched runtime as
packaged builds. It also restores terminal application shortcuts, stabilizes
Markdown previews and native Glass workspace transitions, and keeps Git state
colors semantically consistent.

### Terminal output and scrollback

- Terminal websocket frames now enter xterm's ordered write queue directly, and
  reconnect bytes are acknowledged only after xterm commits each write.
- Axon's manual output batching, scroll tracking, forced redraws, texture-atlas
  clearing, and health-render pipeline have been removed so xterm controls its
  own buffer and renderer lifecycle.
- Full-viewport CSI scroll-up operations retain displaced rows in scrollback
  instead of allowing new output to overwrite terminal history.
- Automatic acceleration uses xterm's resilient DOM renderer, while WebGL
  remains available as an explicit opt-in with context-loss fallback.
- Terminal sessions and renderer state remain mounted when their panel or tab
  is hidden, preserving output across normal workbench navigation.
- Vite excludes xterm from dependency optimization so development serves the
  corrected runtime directly instead of retaining a stale prebundled copy.
- Electron regression coverage streams 1,200 numbered lines, checks xterm's
  buffer, traverses every historical viewport, and rejects missing pixel rows.
- Linux CI runs the same compositor fixture with Electron's WebGL2 software
  renderer rather than replacing it with a synthetic browser-only test.

### Terminal interaction and recovery

- Active terminal panels and tabs restore xterm focus when they become visible.
- Capture-phase editor shortcuts recognize xterm as an application input
  boundary, allowing Codex transcript access and other terminal TUI shortcuts
  to reach the PTY unchanged.
- Opening a terminal link still uses the system browser, but mouse-up now
  reaches xterm's document listener so returning pointer movement cannot extend
  a stale text selection.
- Packaged builds recover the PTY host before requesting a new connection
  ticket after an unexpected exit.
- Failed private PTY control sockets are treated as service outages, and
  repeated connection failures use bounded backoff instead of flooding logs.

### Workbench stability

- Clicking inside an active editor pane no longer rebuilds layout state, while
  selecting a sibling pane still activates it normally.
- Markdown and MDX previews remain mounted through clicks and background Git
  refreshes, preserving images, videos, highlighted code, Mermaid output, and
  other rendered content without periodic flicker.
- Workspace changes remount workspace-owned editors, terminals, menus, and
  transient state at a clean boundary.
- Native Glass receives a visually lossless compositor refresh after a
  workspace switch, preventing pixels from the previous workspace from showing
  through hover damage regions.
- Semantic token refreshes use the latest live theme state, preventing typing
  in an already-mounted editor from restoring colors from the previous theme.

### Git and language tooling

- Git added, modified, deleted, renamed, and conflict states use stable green,
  gold, red, and cyan palettes instead of inheriting ambiguous syntax colors
  from the active editor theme.
- The semantic palette is applied consistently to file decorations, editor
  gutters, minimaps, overview rulers, and diff backgrounds, with contrast-safe
  shades for light and dark surfaces.
- Managed SQL language-server downloads follow SQLS's canonical GitHub
  organization while retaining pinned assets, integrity checks, and trusted
  repository validation.

### Documentation

- The repository gallery now presents Axon's current Glass interface, workspace
  selection, cloning, code intelligence, diagnostics, Git review, terminal, and
  project-output workflows with refreshed screenshots and compact videos.
