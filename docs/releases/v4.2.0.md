## Axon v4.2.0

Axon v4.2.0 is a workbench, agent, and glass release. It adds a full-bleed Zen
canvas with a searchable workspace tree, expands the agent tool loop with glob,
grep, paged reads, file writes, folder creation, and command execution, and
rebuilds the glass surfaces so the workbench, terminal, popups, and folder
picker stay readable. The release also includes the README rewrite and every
commit since v4.1.0.

### Glass and terminal surfaces

- Workbench regions float as rounded cards with a gap between them, and the
  glass region tint is light enough to show the native material while keeping
  the card edges readable.
- Native macOS vibrancy rebuilds when Glass is enabled at runtime instead of
  reusing a stale opaque backing layer.
- The terminal surface becomes glass in Glass mode, and the editor chrome hides
  behind a zoomed terminal without reflowing the editor column.
- Settings search results and folder picker actions use solid, readable
  surfaces in glass themes, and the Spotify panel keeps its fixed brand colors
  and always-visible connect action.
- The docked terminal keeps its workspace setup through a floating handoff,
  including the current directory and setup state.

### Zen workspace

- The full-bleed Zen canvas hides the macOS traffic lights, collapses the
  workbench chrome, and keeps the tab strip draggable.
- Cmd/Ctrl+B opens a workspace tree modal with lazy folder loading, keyboard
  navigation, search results, git tone paint, and a path bar.
- The workspace tree can open as a modal or as the full sidebar through a new
  Appearance setting.
- The tree is split by capability into tree, search, and shared helpers, with a
  reusable draggable modal shell and shared search input.
- Contextual workbench icons animate in and out, the status bar keeps revealed
  text on one line, and the workspace root header is scoped to the files view.
- Git compare opens real workspace files, and file-tree Git status badges give
  way to the existing name and icon tone.

### Agent

- The agent can explore projects with glob, grep, paged reads, and
  breadth-first `list_files`. It can create folders and write files through
  approval cards, and run commands under ask, allowlist, or auto policy.
- File writes are atomic in the main process, while command execution supports
  ask, allowlist, and auto modes with a controlled environment, timeout, output
  cap, and process-tree termination.
- Conversations persist as readable JSON under `~/.axon/sessions`, including
  thoughts, statuses, tool cards, and edit proposals, with a one-time migration
  from localStorage.
- Planning thoughts stream into the timeline while the model works, timeline
  events render in arrival order, and tool results stay in context across
  turns.
- Streaming turns forward the same tool schemas as the non-streaming planning
  path, and the local runtime reuses the planning answer instead of generating
  it twice.
- The model pickers share one surface, separate installed and needs-download
  models, and show a fit note only when the host memory is strained.
- Agent links open workspace files, the sidebar composer and chat scrolling are
  refined, and the `write_file` action adds an approval card with a content
  preview.
- The developer tool environment is typed as `NodeJS.ProcessEnv`, and
  `ci:local` runs the main-process build so local checks catch main TypeScript
  errors before CI.

### Docs

- The README rewrite adds the current Solid Look and Glass Look screenshots,
  badges, download guidance, and development documentation.
