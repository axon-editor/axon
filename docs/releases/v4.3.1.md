## Axon v4.3.1

Axon v4.3.1 is a focused follow-up to v4.3.0. It fixes Git discovery in
packaged builds and stops terminal command suggestions from appearing while a
command is being edited mid-line.

### Git in packaged builds

- Git commands now resolve through the recovered login-shell environment, so a
  Finder or Dock launch sees the same Git binary, hooks, and credential helpers
  as the user's terminal.
- Git discovery runs outside the workspace loading path. A slow or blocked Git
  process can no longer keep the editor in its loading state for minutes.
- The existing status resilience remains: read-only commands avoid optional
  locks, transient failures retry once, repository identity is preserved, and
  failures are written to the Git output channel.

### Terminal suggestions

- Ghost text only appears when the cursor is at the end of the shell input.
- Moving left to edit an existing command now hides the suggestion instead of
  matching the shorter prefix under the cursor.
- Alternate-buffer programs remain excluded from suggestions.

### Included commits

- `728c28e` runs Git in the developer shell environment and off the workspace
  loading path.
- `dc7212a` hides terminal suggestions while editing mid-line.
