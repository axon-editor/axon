## Axon v1.3.9

Axon v1.3.9 is an extensions, Markdown, and AI release. It opens Axon's
extension story to a hosted marketplace with installable webviews and
bundled documentation, replaces the Markdown preview with an owned rendering
pipeline, and moves the assistant into a redesigned chat surface with
conversation search, pinning, and context chips. It also adds native inline
completions, a dedicated settings window, macOS Finder integration, and a
substantial pass of renderer and terminal performance work.

### Extension marketplace

- Extensions install from the hosted axon-editor registry, so a published
  extension reaches users without a manual build or a local link.
- Extension webviews open as ordinary editor tabs instead of replacing the
  workbench, so they participate in normal layout, history, and window state.
- The marketplace presents a detail view per extension with an explicit
  uninstall action and a README rendered from the extension's own manifest.
- Extension README images resolve through Axon's local-asset tickets, so
  documentation renders its own screenshots without exposing filesystem paths.
- Bundled extensions suppress the README pane, since their documentation is
  already part of the application rather than something a user installs.

### Markdown preview

- Markdown rendering is owned by Axon rather than a third-party React library,
  using a line-by-line parser with a plugin system and an HTML renderer built
  on Shiki for syntax highlighting.
- The preview patches the DOM in place with bidirectional scroll sync, so
  re-rendering a paragraph no longer replaces the whole document.
- A code-fence pattern that matched headings no longer sends a large document
  into catastrophic backtracking, removing an out-of-memory crash on long
  files.
- Raw HTML in Markdown is sanitized before it reaches the preview, and line
  numbering aligns with the source document instead of drifting as content
  reflows.
- Local images and media resolve to axon ticket URLs, so relative paths in a
  document preview correctly without a separate asset pipeline.
- Prose renders in the editor font and inline formatting such as emphasis and
  links parses correctly, with local links opening in the editor.
- The preview stays live while typing, and redundant repaints are eliminated
  so a keystroke no longer flickers the whole rendered surface.
- Videos render as centered, bordered cards on a stable 16:9 stage rather
  than bare elements at their intrinsic size, with opt-out classes for inline
  and unframed presentation, and a bare video starts on click.

### AI chat and inline completions

- The chat sidebar was rebuilt on a proper component structure and a refreshed
  visual language, with context chips and a `/` command menu on the input.
- Conversations can be searched, pinned, and managed from a per-message
  context menu, so long threads stay navigable.
- Native inline AI completions are available in the editor, with completion
  details rendered directly in the suggest widget rather than in a separate
  surface.
- The DevTools inspector is restricted to development builds, so a packaged
  release does not expose an inspection surface to anyone who finds it.

### Settings and workspace

- Settings open in a dedicated window with a live preview and convergent save
  behavior, so edits are visible immediately and a window close cannot discard
  them.
- The settings modal is composed from granular per-file sections, and a
  row-level search popup with animated section transitions makes a long
  settings tree navigable.
- The Settings JSON tab reads and writes the global settings file, matching
  the same source of truth as the graphical settings.
- Nested folder expansions in the sidebar survive collapses and restores,
  instead of resetting the tree to its top level on every toggle.

### Git and source control

- Commit author avatars appear across the Git history surfaces, so authorship
  is readable without opening each commit.
- Full commit bodies are shown in the line-trace popover, and blame results
  deduplicate repeated bodies instead of printing the same text repeatedly.
- Git diff surfaces paint rich semantic tokens rather than plain additions and
  removals, and file-status badges use a bordered square that stays legible on
  both light and dark surfaces.
- All Git operations are gated on repository detection, so opening a folder
  without a repository no longer produces failing operations in the UI.

### macOS integration

- Axon registers as a handler for folders, so choosing one in Finder opens it
  in the application rather than creating a new Finder window.
- An "Open in Axon" menu item appears in Finder for folders and directories,
  providing a direct path into an existing workspace.

### Performance and memory

- Main-process file reads no longer use the blocking synchronous variant on
  hot paths, and the text cache fingerprints a file with a single stat call.
- Warm cache hits skip the stat syscall entirely, and a file fingerprint is
  validated from an already-open descriptor rather than a second path lookup.
- File watchers are tracked per path with reference-counted cache trust, and
  every mounted buffer is watched rather than only the focused pane.
- Monaco registers its languages once per session rather than per editor, and
  the Shiki highlighter is warmed for common languages at startup.
- LSP overlay waits adapt to session warmth instead of always paying the cold
  cost, so a warm project stops paying a first-request penalty.
- A click inside an active editor pane no longer rebuilds workbench layout
  state, and select a sibling pane still activates it as expected.
- Renderer memory leaks that grew during long sessions were fixed, and files
  deleted on disk are no longer re-read on every refresh.
- Sidebar folder state and Git blame bodies both avoid recomputing work that
  the previous result already satisfied.

### Terminal

- Past commands are suggested inline in the terminal, detected from the real
  xterm prompt row geometry and the terminal host's actual shell history.
- A zoomed terminal panel stays under user control: its header is clickable
  again, Escape restores the panel, hidden panels reset their zoom state, and
  tabs can be reordered by drag without rebuilding any PTY.
- The close-timer race that could strand a full-window modal over the
  workbench was fixed, and panel control tooltips no longer clamp back over
  their own button while zoomed.

### Maintenance

- Guarded repository pipelines cover Go, editor, filesystem, terminal, and
  build-validation domains, with a required aggregate check gating merges.
- Every application source file carries an MIT copyright header.
- Managed language-server builds are documented for local development, and
  all Tailwind oxide platform binaries are pinned in the lockfile.
- The CLI install prompt follows the active theme instead of forcing its own
  colors, and the Shiki highlighter no longer emits a Vite dynamic-import
  warning.
- Vulnerable npm dependencies were patched, and asset bodies are read through
  the promise API with the response path covered by tests.
