## Axon v1.3.6

Axon v1.3.6 is a presentation, Git workflow, settings, and multi-window
reliability release. It expands the built-in theme catalog, removes unwanted
theme tinting from native Glass, makes settings apply automatically, and brings
Git history and comparison work into the normal editor workflow. It also fixes
terminal ownership and workspace-history behavior when several Axon windows are
open at the same time.

### Themes and native Glass

- Blank Ghibli, Sequoia, Snowfall, Uniform Midnight, and Vitesse Refined join
  the built-in theme catalog with their light and dark variants.
- Axon Parchment keeps its existing identity while adopting the Gruvbox Light
  Soft palette for clearer syntax and editor contrast.
- Imported Zed themes now resolve inherited surface colors, expand shorthand
  hexadecimal colors, and map more editor, guide, selection, search, scrollbar,
  panel, sidebar, and terminal tokens into Axon and Monaco.
- Native Glass no longer mixes the active theme color into persistent editor,
  sidebar, panel, terminal, or window surfaces. The operating-system material
  remains visible while temporary overlays retain readable backing.
- Axon Black is the canonical startup fallback. Missing persisted themes are
  repaired during hydration, and a minimal emergency theme keeps the renderer
  usable even if the extension theme registry cannot load.
- Development and installed builds use separate user-data directories so a
  development-only theme selection cannot prevent the packaged app from
  starting.

### Settings and workspace state

- Settings persist after a short idle debounce and no longer require a Save
  button for each change.
- Closing Settings flushes pending changes through every close path, while save
  sequencing prevents an older asynchronous write from repainting newer values.
- Reset restores the values captured when Settings opened, preserving a clear
  recovery path without bringing back Save and Cancel semantics.
- Electron tracks active workspace folders by renderer window and broadcasts
  changes when windows open, switch roots, or close.
- Open workspaces stay out of Recent folders consistently across all windows,
  recent-folder storage changes update already-open pickers, and selecting an
  existing workspace focuses its current window.
- Workspace paths are normalized before comparison so macOS and Windows path
  representation differences do not create duplicate entries.

### Editor and Git workflows

- Monaco hover content uses a compact Axon surface with theme-aware typography,
  code treatment, links, action rows, and diagnostics.
- Breadcrumb symbol navigation is centered and dismisses reliably when the user
  interacts outside it.
- Monaco construction policy now lives in a typed, memoized options builder,
  keeping editor behavior controls synchronized with the Editor settings page.
- Git commit file comparisons open as normal virtual editor tabs instead of
  modal-only views, so comparisons participate in the existing pane and tab
  workflow.
- Git graph and file-history results are cached by repository and query state,
  avoiding repeated repository reads when unrelated React state changes.
- Git Graph is available directly after Source Control in the status bar.
- Graph lanes, change states, gutter marks, badges, danger surfaces, history,
  worktrees, confirmation dialogs, and Monaco diff editors derive their colors
  from the active theme.
- Axon confirmation dialogs replace native browser confirmations for destructive
  Git actions, keeping interaction and appearance consistent with the workbench.
- Diff model ownership is explicit during tab and modal teardown, preventing a
  closed comparison from disposing models that another editor still uses.

### Multi-window and packaged application reliability

- Terminal host health probes no longer treat a slow response as a process
  crash, avoiding false restart prompts while several windows run terminals.
- Restart confirmation is reserved for an actual PTY host process exit, and
  overlapping watchdog probes cannot create competing recovery flows.
- Terminal sessions register before output readers start, and simultaneous
  reconnects cannot orphan duplicate shell processes.
- The packaged macOS application keeps its generated bundle icon in the Dock
  instead of switching to old or transparent renderer artwork after launch.
- Git contribution delivery remains available to workbench overlays without an
  unused local layout binding, restoring the strict renderer release check.

### Documentation

- The complete Current Features inventory now lives in dedicated documentation,
  leaving the root README focused while retaining a direct human-readable link.
