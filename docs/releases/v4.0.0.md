## Axon v4.0.0

Axon v4.0.0 is a focus, terminal, and glass release. It adds a zen aesthetic
mode that strips the workbench down to the code, moves the terminal into its
own operating-system window with a handoff that keeps live sessions alive, and
gives the floating terminal real resize behavior. It also unifies the git line
paint across the editor and the diff, eliminates the ghost frames that stacked
behind native glass popups, and reorganizes the editor and CLI sources into
domain folders without a behavior change.

### Zen aesthetic mode

- Zen mode hides the toolbar, sidebar, status bar, and footer, leaving the
  editor and a minimal tab strip in place of the normal chrome.
- Commands stay reachable while the chrome is hidden through Cmd+Shift+A, M, U,
  and T, with a `:command` readout pulsing to confirm the keypress.
- Zen toggles cross-fade the workbench chrome instead of snapping, and panels
  and sidebar collapse on entry and restore their previous layout on exit.
- The tab strip shrinks to a 30px row with pin and close hidden, and the blank
  strip that sat above it was removed so the strip itself becomes the window
  drag region.
- Exiting zen no longer depends on a button: Escape, Cmd+Shift+Z, or the
  command palette all leave the mode.

### Floating terminal window

- The terminal panel can float into a dedicated OS window, and the live PTY is
  handed off rather than restarted, so a running shell survives the move.
- Input produced while the terminal is floated is replayed as a byte delta when
  the panel docks again, and xterm instances stay mounted so the replay lands
  in the same buffer.
- Closing the window is intercepted and replayed as a dock handshake, with a
  700ms fallback that force-docks the window if its renderer never answers.
- The floating terminal resizes from every edge and corner, anchored to the
  opposite edge with minimum-size clamping that mirrors the docked rect.
- The docked terminal panel collapses to a slim dock bar while floating, and
  the terminal module was split into components, hooks, and a slim wiring
  entry.
- macOS command chords keep working while the terminal has focus, while Ctrl
  and Alt sequences and plain keys stay with the PTY.
- A Tab-accepted suggestion no longer moves focus onto the next toolbar
  control, so the selection stays in the terminal.

### Git and source control

- The editor and the diff now share one git line paint, so a modified line
  reads as Axon gold in both surfaces instead of a native green insertion in
  the diff.
- Changed files render for every node in the git graph: the history pretty
  format now ends in a newline so the parser sees the commit body, and a
  dedicated commit-detail request backs the graph.
- The diff modified pane no longer marks a deletion on the wrong line, and the
  removed pane keeps the native tint Monaco still owns.
- The git side-by-side diff shows the native material through transparent
  panes, matching the main editor, and its empty-range marker is visible again.
- The diff paints one token collection per side instead of accumulating a new
  collection on every semantic-token update.

### Native glass and window chrome

- Ghost frames behind native glass popups were removed by containing the
  composited layers, so a partial re-render fully repaints instead of leaving
  the previous frame stacked underneath.
- The compositor is flushed when App Glass activates or retints, reusing the
  workspace repaint pulse instead of keeping a second copy.
- Persistent chrome surfaces stay barely tinted so a hover always repaints
  against a real backdrop, and a theme that omits a token falls back to the
  current appearance instead of a fully clear surface.
- The compositor changes that could not affect a clear renderer surface were
  reverted, and the resolved appearance is passed to the glass fallback so a
  light theme stops falling back to the dark neutral.
- Workbench chrome no longer keeps the toolbar menus behind the editor pane,
  and the tab strip drag band no longer swallows clicks on the popovers, the
  modal overlay, or the compare modal.

### Editor and language tools

- `.mdx` files are recognized as Markdown for highlighting and routed to the
  bundled MDX language server.
- Method body tokens no longer inherit the function color: only the method name
  token matches, by requiring the method definition scope alongside the
  function name.

### Workspace and reliability

- Settings and editor windows resolve their preload and renderer paths after
  the window sources moved into `window/create`, so the settings window boots
  with `window.axon` available.
- The test explorer refresh no longer spins forever: the discovery effect reads
  the output callback through a ref and keys its listeners on the workspace.
- CI test paths point at the reorganized editor and filesystem test locations.
- The macOS first-launch block on unsigned builds is documented, naming both
  the "damaged" and "not trusted" Gatekeeper dialogs and the routes past them.

### Maintenance

- Editor, extension, and builtin sources were split into per-concern domain
  subfolders, and the CLI was split into domain subpackages, with imports
  updated and no behavior change.
- Root scripts were added for the checks CI runs, including a `typecheck` that
  points at the app tsconfig and wrappers for the extension registry and
  language-server checks.
