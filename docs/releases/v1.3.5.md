## Axon v1.3.5

Axon v1.3.5 is a focused workflow and presentation release. It finishes the
terminal rendering work from v1.3.4, adds reliable automatic saving and
Prettier-backed formatting, introduces native application glass, improves AI
model selection, and replaces the compact folder picker with a complete opening
and cloning workflow.

### Terminal rendering and input

- Terminal tabs can use xterm's WebGL renderer for smoother output while only
  the visible tab holds a GPU context. Hidden tabs retain their complete buffer
  and PTY session through the DOM renderer.
- WebGL initialization failures and context loss fall back to DOM rendering
  instead of leaving a blank terminal or repeatedly recreating an unstable GPU
  context.
- Terminal settings expose persisted automatic, enabled, and disabled GPU modes
  so users can choose reliability or acceleration for their machine.
- Scrollback repainting now covers newly exposed rows and settled trailing
  frames without moving a reader who has scrolled away from the live tail.
- Electron compositor surface recycling preserves the visible WebGL drawing
  buffer, reducing output that only appeared after resizing the terminal.
- Terminal sessions advertise truecolor support and no longer inherit
  `NO_COLOR`, allowing agents, shells, and command-line tools to render their
  authored ANSI colors normally.
- Axon's terminal clear command is limited to unmodified `Cmd+K`. `Ctrl+K` and
  modified key combinations continue to reach readline, shells, editors, and
  interactive agent prompts.

### Saving and formatting

- Auto Save uses a one-second trailing delay and persists as an editor
  preference across restarts.
- The native File menu, Command Palette, and Ergonomics settings expose the same
  synchronized Auto Save state.
- Each dirty buffer schedules independently, so continued work in one tab does
  not postpone saving another file.
- Shared Monaco models visible in multiple panes produce one coordinated save,
  while detached models retain a direct save path when no editor is mounted.
- Bundled Prettier is now the primary formatter for supported JavaScript,
  TypeScript, web, configuration, and Markdown documents.
- Project Prettier configuration remains authoritative, editor indentation
  preferences are supplied when the project has no stronger rule, and language
  server formatting remains available for languages outside Prettier's scope.

### Application glass and interface

- macOS uses native vibrancy materials and Windows uses system backdrops, with
  the selected glass mode available as soon as a new window is created.
- Off, system glass, and live glass modes are persisted alongside opacity and
  local surface-blur controls.
- Editor chrome, sidebars, toolbars, panels, and modal surfaces participate in
  one native backdrop while selectors, tooltips, context menus, and Monaco code
  hover remain opaque enough for reliable reading.
- Modal and popup frost adapts to theme appearance. Light themes such as Axon
  Parchment receive denser low-saturation contrast, while dark themes retain a
  deeper glass treatment.
- The workspace empty state exposes New File only where Axon has a writable
  workspace, removing an action that could not work before a folder was opened.
- Editor typography presets now affect code only and preserve the interface font
  selected in Appearance.

### Folders, cloning, and editor feedback

- Open Folder is now a wider responsive workflow with dedicated Local folders
  and Clone repository tabs.
- Workspace roots and recent folders have separate scrollable sections, active
  workspace state, recent-folder filtering, individual removal, and cleanup
  controls.
- Browsing closes Axon's modal before Electron opens the native folder dialog,
  avoiding competing overlays during workspace replacement.
- Repository cloning keeps its URL, progress, and errors mounted when switching
  tabs and opens a completed checkout through the normal workspace path.
- Axon Line Trace validates that the pointer still targets a live Monaco widget
  before displaying commit details.
- Trace popovers dismiss when widgets move, editors scroll, windows blur, or the
  document becomes hidden, preventing detached commit details from remaining on
  screen.
- AI settings use Axon's searchable model catalog, show model descriptions and
  download requirements, preserve custom saved model IDs, and provide explicit
  refresh progress and failure feedback.

### Language reliability

- YAML language-server startup now handles npm layouts where build tooling
  hoists AJV 6 beside `ajv-draft-04`, even though that adapter requires AJV 8.
- Axon places YAML's own compatible AJV runtime at the adapter's nearest Node
  resolution boundary before development and release builds.
- ESLint, Electron Builder, and other AJV 6 consumers keep their expected major;
  the fix is scoped to YAML instead of replacing a shared dependency globally.
